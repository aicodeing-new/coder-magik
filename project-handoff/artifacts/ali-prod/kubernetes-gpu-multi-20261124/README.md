# Kubernetes 多机 GPU 工作空间

同一集群申请 2 到 4 台不同的物理节点，可设置每台 GPU 数量和镜像。每台有独立 HOME PVC。节点不足时等待调度。

使用 Pod 网络。每台机器有单独的 Coder Agent 与稳定的集群内 DNS 名。打开任意机器的终端，运行 `cat ~/hosts.txt` 查看所有节点的可连接地址。服务需监听 Pod 网络，跨节点通信使用业务自己的端口和认证。首次启动时 DNS 在 Pod 就绪后更新。应用需要在所有节点就绪后再启动集体通信任务。

该模板供测试使用。GPU 设备、RDMA 和实际性能应在试点集群实测。停止时释放 Pod 和 GPU，保留独立 HOME PVC。
